# Custom Full-Stack Web Application

A lightweight, responsive web application handcrafted entirely from scratch using pure code without website builders or heavy frameworks.

## 🛠 Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Backend:** JS

---

## ✨ Key Features

* **Handcrafted UI:** Built completely from scratch for optimal performance and clean DOM structure.
* **Responsive Design:** Optimized for mobile, tablet, and desktop views.
* **Custom Backend Logic:** Clean API/routing architecture handling server-side processing.
* **Cross-Browser Compatibility:** Tested and functional across all modern browsers.
